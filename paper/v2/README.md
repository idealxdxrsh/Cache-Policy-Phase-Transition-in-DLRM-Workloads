# paper/v2: IEEEtran conference paper (two-column, 10 pt)

Title: *Rotate-Victim: A One-Pointer Tie-Break Fix for Hardware LFU Embedding Caches, from Criteo Traces to 28nm
FD-SOI Layout*. Authors: Adarsh; Pravin Mane (Department of Electrical and Electronics Engineering, BITS Pilani,
K K Birla Goa Campus). The previous version (NanGate45 only) is in git history (`git show ab20c1d:paper/v2/main.tex`).

Earlier working title (dropped as overstated): "A Tie-Break Rule Decides Whether a Hardware LFU Embedding Cache Beats
LRU: Trace Study and 28nm FD-SOI Implementation".

## Numbers
Every number in `main.tex` is written `\R{key}`. `macros.tex` defines each key and is generated by
`tools/make_paper_macros.py` from committed results files (`git show HEAD:`); each definition ends with a comment
giving the source file, line, table row and column (or regex) and the full source value. Display rules: hit rates
rounded half-up to 2 decimals; differences computed from the full values, then rounded; every other value exactly as
written in the source. `tools/paper_numbers_check.py --macros paper/v2` checks every sentence, table cell and
caption: a digit outside `\R{}` (other than names such as H100, 28nm, mode 0), an undefined key, a definition without
a `results/` source, the word TSMC, a stale `macros.tex`, more than 3 distinct numbers in a prose paragraph or list
item, or more than 6 in the abstract fails the build (tables and captions carry the detail). Its output is
`numbers_check.txt`. Power is shown in mW by moving the decimal point of the W value (same digits); the L2 size in MiB
is an exact division by 1,048,576.

Area units: Genus states no unit in its area report, so synthesis areas are in library units; Innovus reports um^2
(results/P15/TABLES.md: "um2 as reported by Innovus"), so post-route areas are in um^2.

Technology naming (approved by Prof. Mane, 2026-11-19; CLAUDE.md): "an STMicroelectronics 28nm FD-SOI standard-cell
library (accessed through CMP)" at first mention, "the 28nm FD-SOI library" elsewhere; no cell or file names, paths,
metal stack, host or user names. Run `python3 -I tools/check_no_lib_leak.py` before any commit.

## Build (needs matplotlib 3.8.4 in `.venv`, latexmk)
```
cd paper/v2 && make        # macros, number check, figures, PDF; stops if the number check fails
make check                 # macros and number check only
```
Figures read committed files only, so commit new results before regenerating them.
